Advanced Dynamic Many2One Search & Display Multiple Fields for Partner/Customer/Vendor (Odoo16)

By default, Odoo allows searching customers only by name and displays only the name in Many2One fields. This module enhances the Many2One search and display functionality by enabling users to search using multiple fields (Phone, Email, Mobile, etc.) and display multiple values directly inside the Partners Many2One selection.

-Search and display multiple fields in Many2One (e.g., Name, Email, Phone)

-Fully Configurable – Select search and display fields dynamically from settings

-Improves Workflow Efficiency by reducing search time

-Works in Many2One Fields across different modules

-With this module, businesses can efficiently search and identify customers based on multiple details—no more hassle of searching only by name!

Key Features

  • Multi-Field Customer Search:Search customers using Name, Phone, Email, Mobile, or any additional field dynamically.

  • Easy Configuration:Define search and display fields from Odoo Settings without any coding.

How to Configure the App?

  • Install the Module from Odoo App Store.
  • Go to Settings > General Settings
  • Find the section Customer Search Fields and Customer Display Fields under Discuss.
  • Select the fields you want to include in the search or display (e.g., Name, Mobile, Email, Custom Fields).
  • Save settings, and now you can search and display customers using the selected fields.
