Bank Reconciliation Report – Check Date & Check Number with Dynamic Check Date Filter (Odoo 18)

This Odoo 18 module enhances the Bank Reconciliation Report by adding two essential fields Check Date and Check Number making it easier to track payments and reconcile transactions more precisely.

Additionally, it introduces a "Check Date Filter" configuration in: Accounting > Configuration > Accounting Reports > Bank Reconciliation Report.

When enabled, this filter displays a Check Date Filter option directly on the Bank Reconciliation Report page, allowing users to filter data by As on Date or by a Custom Date Range (From / To).

This module helps accountants, auditors, and financial managers quickly reconcile transactions based on check issuance or clearing dates, improving financial visibility and reducing manual filtering effort.

Key Features

  • Adds "Check Date" and "Check Number" columns in the Bank Reconciliation Report.
  • Enables a dynamic Check Date Filter with "As on Date" and "Custom Date Range" options.
  • Configurable from Accounting Settings enable or disable the Check Date Filter as needed.
  • Filter transactions based on check issuance or clearing dates for precise reporting.
  • Enhances reconciliation accuracy and reduces manual work.
  • Seamless integration: Works seamlessly with Odoo 18 Accounting Reports framework.
  • Ideal for finance teams who manage high transaction volumes or multiple check payments.

How to Configure

  • Go to Accounting > Configuration > Accounting Reports > Bank Reconciliation Report.
  • Enable the "Check Date Filter" checkbox.
  • Navigate to the Bank Reconciliation Report.
  • A Check Date Filter button will now appear.
  • Choose either:
    • As on Date – to view reconciliations up to date.
    • Custom Date Range (From / To) – to filter records within a specific range.
  • The report will automatically filter based on the selected check dates.
