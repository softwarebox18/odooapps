Stock Availability Control for Salesman – Block Delivery & Internal Transfers When Stock Is Insufficient (Odoo18)

This Odoo module adds an automatic stock validation rule for users belonging to the Salesman group. It prevents the creation or validation of Delivery Orders (Outgoing Transfers) and Internal Transfers when the available stock is less than the ordered quantity, ensuring that no product is delivered or moved without sufficient inventory.

The module extends the standard Odoo warehouse flow by introducing real-time stock checks during both record creation and validation stages.

It works only for users in the Salesman group, allowing managers and administrators to bypass the restriction for operational flexibility.

This module depends on

mh_salesman_group (Salesman Groups Module)

Key Features

  • Automatic Stock Check:Before creating or validating Delivery Orders and Internal Transfers.
  • Blocks transactions:When available stock is lower than the ordered quantity.
  • Applies only to Salesman group users:Keeping control strict yet flexible.
  • Works on both record creation and validation stages:To prevent data bypass
  • Accurately calculates available stock:Including reserved quantities in real time.
  • Seamless integration:With Odoo’s stock and warehouse flow.
  • Depends on:mh_salesman_group to manage access and group-based restriction.

How to Configure

  • Install the dependency module "Salesman Groups (mh_salesman_group)".
  • Navigate to Settings, Users & Companies, Users.
  • Open a user form and assign the Salesman group (Salesman under Sales category).
  • Install this module.
  • When a Salesman tries to:
    • Create a Delivery Order (Outgoing Transfer)
    • Create an Internal Transfer
  • The system will automatically validate available stock.
  • If the available quantity is less than required, a User Error will be displayed and the operation will be blocked.
  • Other users (like Admin or Managers) can still proceed without restriction.
