Multi-Company Auto Selection | Default & All Companies Toggle for Odoo (Odoo16)

Enhance your Odoo multi-company management with automatic company selection based on your preferences. This module allows users to auto-select all companies by default or restrict selection to only the default company, providing flexibility and better control over company access.

If enabled, all companies are selected by default.

If disabled, only the default company remains selected.

Ideal for businesses managing multiple companies in Odoo, this app streamlines company switching, improves user efficiency, and reduces manual selections.

Key Features

  • Auto Select All Companies:Enable the setting to have all companies selected automatically.
  • Default Company Selection:If disabled, only the default company remains selected.
  • Seamless Integration:Works within Odoo’s native multi-company switcher.
  • No Manual Selection Needed:Saves time and reduces errors.
  • Lightweight & Fast:No performance impact on Odoo.
  • User-Friendly:Simple configuration, no technical knowledge required.

Configuration

  • Simply install the module from the Odoo app store, and the new functionality will be added.
  • Locate the option "Allowed All Companies By Default".
  • Check the box to auto-select all companies by default.
  • Uncheck the box to keep only the default company selected.
  • Save changes – the selection applies instantly!
