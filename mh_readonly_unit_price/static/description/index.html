Readonly Unit Price in Product, Sale Order Lines and Invoice Lines By User Group (Odoo17)

Control who can edit unit prices! This app allows you to restrict editing of unit prices on Product forms, Sale Order Lines, and Customer Invoice Lines based on a specific user group called Edit Unit Price.

By default, users cannot modify unit prices, improving accuracy, preventing unauthorized changes, and maintaining pricing integrity across sales and finance workflows.

Key Features

  • Make Unit Price Read-Only for Unauthorized Users
  • Controlled by User Group "Edit Unit Price"
  • Works on Product, Sale Orders, and Invoices
  • Lightweight & Easy to Integrate
  • Compatible with Odoo Security Rules
  • Ideal for Price Control and Approval Workflows

Configuration

  • Simply install the module from the Odoo app store, and the new functionality will be added.
  • Go to Settings > Users & Companies > Groups.
  • Find or search for "Edit Unit Price" group.
  • Add users to this group who should be allowed to edit unit prices.
  • That’s it! All other users will see the unit price field as read-only.
