Display Serial Number and Image in Sale Order Line and Report (Odoo18)

Enhance your Odoo sale order reports by adding serial numbers and product images dynamically! This module allows you to display serial numbers and product images in quotations and sales orders with just a simple configuration. Improve readability, provide a professional look, and make it easier for customers to understand their orders. This module allows you to:

Automatically assign serial numbers to each sale order line

Restart serial numbering when a custom string (e.g., “A”) is used as a serial number

Show product images in sale order reports, with flexibility to add custom images

Individually configure these features through Odoo settings—no coding required!

Key Features

  • Smart Serial Numbering:Each product line gets an auto-generated serial number (1, 2, 3… etc.). If a serial number is manually set to a custom string (e.g., “A”), the next product resets numbering to 1.
  • Flexible Product Images:If a product has an image, it will automatically be shown in the sale order line report. If a product has no image, you can manually upload an image in the sale order line. Custom images in the sale order line do NOT affect the original product image in the product catalog.
  • User-Controlled Settings:Activate/deactivate features with a simple toggle in settings
  • Optimized Performance:Lightweight module, ensuring smooth Odoo functionality.
  • User-Friendly:Simple configuration, no technical knowledge required.

Configuration

  • Simply install the module from the Odoo app store, and the new functionality will be added.
  • Go to Settings and click on Sales.
  • Under Quotations & Orders Settings, enable: Show Serial Number in Report (To Display Serial Number in Quotation / Sale Order Report) and Show Product Image in Report (To Display Product Image in Quotation / Sale Order Report)
  • Click Save your sale order printouts will now include serial numbers & product images!
