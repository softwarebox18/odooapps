Multi-Company User Group & Menu Access Manager (Odoo18)

Are you managing a multi-company setup in Odoo and need company-specific user access and menu visibility?

This Multi-Company User Group & Menu Access Manager allows you to assign user groups per company and dynamically control menu visibility based on selected companies.

With this app, you can:

-Assign Different User Groups for Each Company

-Automatically Update User Groups on Company Change

-Show/Hide Menus Based on User Groups & Company Selection

-Prevent Admin Users from Losing Super Access

-Seamless Multi-Company Management Without Manual Effort

This app ensures that users only see the menus and have access to groups relevant to their assigned company, eliminating confusion and unauthorized access.

Key Features

  • Multi-Company Group Assignment:Assign different user groups to each company for individual user access.
  • Automatic Group Switching:When a user switches companies, the assigned groups update dynamically.
  • Menu Access Control:Menus appear or disappear based on the assigned groups of the selected company.
  • Retains Internal User Access:Ensures users always belong to at least the "Internal User" group.
  • No Access Overwrite for Admins:Prevents admin users from losing ERP Manager access.
  • Automatic Restriction of Sensitive Menus:Automatically assigns sensitive menus to the "No One" group for controlled access.
  • Seamless Integration:Works seamlessly within the Odoo security and multi-company framework.

Configuration

  • Install the Module from Odoo App Store.
  • Navigate to Users & Companies > Users and select a user.
  • Go to the new Company Groups and Menu Access Rights tab.
  • Assign Companies and User Groups per company.
  • Save the changes, and the system will dynamically update the user’s access when they switch companies.
